# 川釣りナビ（v2）

全国の川の「今日の川の状態（雨量・天気・水位）」「遊漁券の料金と買える場所」「解禁日」「禁漁区」を川ごとにまとめる釣り人向けサイトです。最初のサンプルは大分川（大分川漁業協同組合）です。

## しくみ

- **データ**：`data` フォルダのJSON。ふだん触るのはここだけです。
- **自動生成**：GitHubに保存すると `build.js` が動き、サイト全体を作り直して GitHub Pages に公開します。
- **自動更新（1時間ごと）**：気象庁のアメダス雨量・天気予報を取り込み、「川の状態（増水・濁りの目安）」を更新します。雨量計は各川の緯度・経度から一番近いものを自動で選びます。
- **自動チェック（毎週月曜）**：県・漁協の遊漁規則ページやPDFの変更を検知すると、GitHubの「Issues」に確認依頼を自動で作ります。

## 自動で作られるページ

| ページ | 例 | ねらう検索 |
| --- | --- | --- |
| 川 | `/oita/oitagawa/` | 大分川 釣り／遊漁券／ライブカメラ |
| 魚（独自の決まりがある魚だけ） | `/oita/oitagawa/ayu/` | 大分川 鮎 解禁 |
| 釣り場（ダム湖など） | `/oita/oitagawa/serikawa-dam/` | 芹川ダム ワカサギ／遊漁券 |
| 都道府県 | `/oita/` | 大分 川釣り スポット |
| 解禁日一覧（全国・県別） | `/kaikin/ayu/`、`/kaikin/ayu/oita/` | 鮎 解禁日 2026 大分 |
| 料金一覧・遊漁券ガイド | `/ryokin/`、`/guide/yugyoken/` | 遊漁券 値段／いらない |

掲載河川が少ない一覧ページは、品質を守るため検索エンジンに登録しない設定になっています（`data/site.json` の `aggregateMinRivers`、初期値3）。

## ファイル

| ファイル | 中身 |
| --- | --- |
| `data/site.json` | サイト名・アドレス・Google連携・広告ID |
| `data/rivers/<県>/<川>.json` | 川ごとのデータ（漁協・料金・魚・釣り場・禁漁区・販売店・お知らせ） |
| `data/prefectures.json` | 47都道府県・気象庁の予報区・準備中の漁協 |
| `data/species.json` | 魚の名前と説明、解禁日一覧ページの設定 |
| `data/_templates/river-template.json` | 川を追加するときのひな形 |
| `build.js`・`lib/`・`tools/`・`src/` | プログラム・デザイン（触らない） |
| `.github/workflows/` | 自動公開・自動チェックの設定（触らない） |

## 手元で確認する場合（任意）

Node.js 20 以上で `node build.js`（気象庁に接続しない場合は `SKIP_LIVE=1 node build.js`）。`dist` にサイトができます。

## 注意

掲載情報は各漁協の遊漁規則などの公開資料にもとづきます。公開前・規則改正時は必ず漁協に確認してください。雨量・天気は気象庁ホームページのデータを加工して作成しています。
